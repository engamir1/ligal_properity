## 🚀 طريقة التشغيل والرفع على GitHub Pages

### 1. التشغيل المحلي:
- قم بفتح ملف `index.html` في أي متصفح ويب مباشرة.
- أو شغّل خادم محلي:
```bash
python -m http.server 8000
```
ثم افتح `http://localhost:8000`.

### 2. الرفع على GitHub Pages:
```bash
git init
git add .
git commit -m "Initial commit: State Land Regularization Presentation Deck"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/REPO_NAME.git
git push -u origin main
```
ثم من إعدادات المستودع على GitHub:
- توجّه إلى **Settings** > **Pages**.
- في قسم **Build and deployment**، اختر الفرع **main** والمجلد **/(root)** ثم اضغط **Save**.
- سيكون الموقع متاحاً على: `https://YOUR_USERNAME.github.io/REPO_NAME/`
